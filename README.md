## 업로드 방법

### 방법 1 — 스크립트 실행 (권장)

| 운영체제 | 파일 |
|---|---|
| Windows | `깃허브_올리기_윈도우.bat` 더블클릭 |
| macOS | `깃허브_올리기_맥.command` 더블클릭 |

실행하면 Username과 Password를 묻습니다.
- **Username** : `cholmi1`
- **Password** : 계정 암호가 아니라 **Personal Access Token**
  (GitHub → Settings → Developer settings → Personal access tokens → Generate new token → `repo` 권한 체크)

토큰을 붙여넣어도 화면에는 아무것도 표시되지 않습니다. 정상이니 그대로 Enter를 누르십시오.

### 방법 2 — 웹 브라우저

1. https://github.com/cholmi1/CLAUDE_CHINA 접속
2. **Add file → Upload files**
3. 이 폴더 안의 내용물(`index.html`, `README.md`, `docs` 폴더)을 끌어다 놓기
4. 아래 **Commit changes** 클릭

토큰이 필요 없습니다.
